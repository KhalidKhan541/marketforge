## ✨ Features

### E-commerce Modules (25+ pages)
- 📊 **Dashboard** — Revenue, orders, customers overview
- 📈 **Analytics** — Revenue trends, traffic sources, conversion funnel
- ⚡ **Real-time** — Live visitor count, activity feed
- 📦 **Products** — Catalog management with variants
- 📁 **Collections** — Product groupings
- 📋 **Inventory** — Stock tracking across warehouses
- 🏷️ **Categories** — Product categorization
- 🛒 **Orders** — Full order lifecycle
- 📦 **Fulfillment** — Warehouse picking and packing
- ↩️ **Returns** — Return management and analytics
- 💳 **Payments** — Transaction history and status
- 👥 **Customers** — Customer profiles and history
- 🎯 **Segments** — Customer segmentation
- ⭐ **Reviews** — Product review management
- 🎁 **Loyalty** — Points and tier-based rewards
- 📢 **Campaigns** — Marketing campaign management
- 🎫 **Coupons** — Discount codes
- 📧 **Email** — Email templates
- 🔍 **SEO** — Search engine optimization
- 🚚 **Shipping** — Carrier and rate management
- 💰 **Taxes** — Tax rule configuration
- 🏭 **Warehouses** — Multi-warehouse management
- 📱 **POS** — Point of sale checkout
- 🌐 **Storefront** — Online store configuration
- 👥 **Team** — Role-based access control
- 🔑 **API** — RESTful API access
- 💳 **Billing** — Subscription management
- ⚙️ **Settings** — Store configuration

### Platform Features
- 🌙 Dark / Light / System mode
- 🎨 White-label ready (CSS variable theming)
- 📱 Fully responsive
- ⚡ No database required (mock data)
- 🧩 Modular architecture

## 🚀 Getting Started

```bash
git clone https://github.com/KhalidKhan541/marketforge.git
cd marketforge
npm install
npm run dev
```
